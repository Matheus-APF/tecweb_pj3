# TaskPilot — TecWeb Projeto 3

### Planejador Inteligente de Projetos e Tarefas com IA Generativa

## Descrição do Projeto

O **TaskPilot** é uma aplicação web de gerenciamento de projetos e tarefas que utiliza Inteligência Artificial generativa para transformar objetivos em planejamentos estruturados e personalizados. O usuário pode criar objetivos, definir prazos e informar sua disponibilidade. A partir dessas informações, a IA gera um planejamento com tarefas, prioridades e estimativas de esforço. A plataforma também permite acompanhar o progresso dos projetos por meio de quadros Kanban, gerenciar backlogs, editar tarefas e registrar anotações gerais ou individuais. O projeto será desenvolvido utilizando **React** no frontend e **Django REST Framework** no backend, com integração à API do **Google Gemini**.
